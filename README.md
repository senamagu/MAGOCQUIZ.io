# 画像利用について

このフォルダ・サイト内に掲載されている画像について、以下の範囲で利用してください。

## OK

* 個人での鑑賞・保存
* SNS等に公開しない範囲での加工・編集
* 個人的な創作・作業の参考としての利用
* サイト・ページ等のスクリーンショット撮影
* スクリーンショットをSNS等へ掲載すること

## NG

* 画像ファイルそのもののSNS・Webサイト等への転載・再配布
* 自作発言、無断転載、二次配布
* AI学習・生成AI等への読み込み
* 画像ファイルを加工・改変したものの公開・配布

※「スクリーンショットのSNS掲載」は可能ですが、スクリーンショットから画像部分だけを切り出して転載・配布することはできません。
